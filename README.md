# Sentiment Analysis of Movie Reviews and Recommendation System

## Overview

The Sentiment Analysis of Movie Reviews and Recommendation System is a machine learning-based application that analyzes user reviews of movies and predicts the sentiment expressed in those reviews. Based on sentiment analysis and movie-related data, the system provides personalized movie recommendations to users.

This project combines Natural Language Processing (NLP), Machine Learning, and Recommendation System techniques to improve the movie selection experience. By understanding user opinions and preferences, the system helps users discover movies that match their interests.

## Objectives

* Analyze movie reviews and determine whether the sentiment is positive, negative, or neutral.
* Process and clean large textual datasets for machine learning applications.
* Build a recommendation engine that suggests relevant movies.
* Improve user experience by combining sentiment analysis with recommendation techniques.

## Features

* Movie review sentiment classification.
* Data preprocessing and text cleaning.

## Installation

Clone the repository:

```bash
git clone https://github.com/MaheshK006/Sentiment-Analysis-of-Movie-Reviews-and-Recommendations-System1.git
```

Navigate to the project directory:

```bash
cd Sentiment-Analysis-of-Movie-Reviews-and-Recommendations-System1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
